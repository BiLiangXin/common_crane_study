# Statistical and Sensitivity Analyses / 统计与敏感性分析

## Overview / 项目概述

This directory contains the statistical analyses, robustness checks, sensitivity analyses, data tables, figures, and supplementary documents prepared for the *Ecological Informatics* revision of the Common Crane migration and artificial light at night (ALAN) study.

本目录收录白鹤迁徙与夜间人工光（ALAN）研究在 *Ecological Informatics* 返修过程中使用的统计分析、稳健性检验、敏感性分析、数据表、图件和补充材料。

## Directory and file guide / 目录与文件说明

| Path / 路径 | English description | 中文说明 |
| --- | --- | --- |
| `Code/Code_S1_Habitat_Robustness.py` | Habitat-level threshold and scoring sensitivity analyses, exact group comparisons, and internal convergence tests. | 栖息地层面的阈值与评分敏感性分析、精确组间比较和内部收敛性检验。 |
| `Code/Code_S2_CEq_Annual_Sensitivity.py` | Annual corridor-scale CEq sensitivity analysis and generation of the combined 500-PPI sensitivity figure. | 年度廊道尺度 CEq 敏感性分析，并生成 500 PPI 的组合敏感性图。 |
| `Code/requirements.txt` | Python dependencies for the supplementary analyses. | 补充分析所需的 Python 依赖。 |

## Main combined figure / 主要组合图

`Code/outputs/combined_sensitivity_panels.png` combines the STDHNLPI classification-threshold sensitivity analysis (panel A) and the annual corridor-scale expected ALAN exposure sensitivity analysis (panel B). The figure uses Times New Roman and is exported at 500 PPI. The legend in panel A reports `Thresholds -20%`, `Thresholds +20%`, and the `1:1 line`.

`Code/outputs/combined_sensitivity_panels.png` 将 STDHNLPI 分类阈值敏感性分析（A 图）和年度廊道尺度预期 ALAN 暴露敏感性分析（B 图）横向组合。图件使用 Times New Roman 字体，并以 500 PPI 输出；A 图图例包含 `Thresholds -20%`、`Thresholds +20%` 和 `1:1 line`。

## Reproduction / 复现方法

Install the required packages and run the scripts from the repository root:

安装依赖后，在仓库根目录运行以下脚本：

```powershell
python -m pip install -r "Statistical and sensitivity analyses/Code/requirements.txt"
python "Statistical and sensitivity analyses/Code/Code_S1_Habitat_Robustness.py"
python "Statistical and sensitivity analyses/Code/Code_S2_CEq_Annual_Sensitivity.py"
```

By default, generated results are written to `Statistical and sensitivity analyses/Code/outputs/`.

默认情况下，生成结果将写入 `Statistical and sensitivity analyses/Code/outputs/`。
